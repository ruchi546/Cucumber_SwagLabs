# Cucumber WebdriverIO - Swag Labs Portfolio Project

BDD test automation project using Cucumber and WebdriverIO on the Swag Labs (saucedemo) web app.

## Project Overview

I built this suite to validate key customer flows from login to checkout, with a structure that is easy to maintain and scale. Leveraging Behavior-Driven Development (BDD) principles with Gherkin feature files for clear, readable test scenarios.

## What This Demonstrates

- Behavior-Driven Development (BDD) with Gherkin syntax
- End-to-end test automation for user journeys
- Page Object Model for reusable, maintainable test design
- WebdriverIO for cross-browser automation

## Covered User Flows

- **Authentication**: valid and invalid login behavior, locked users, error messages
- **Inventory**: product visibility, filtering, cart actions
- **Sidebar**: navigation, logout, app state management

## Tech Stack

- Cucumber (BDD Framework)
- WebdriverIO
- JavaScript
- Node.js and npm
